# 财务前端组件与页面分层

本文件把 `PRODUCT.md` / `DESIGN.md` 的原则落实到 WHT 与 TAX INV 页面结构。新增业务
功能默认按这里组合，避免每个页面重新定义标题、间距、颜色和交互。

## 页面层级

1. 应用级：侧栏切换 WHT、TAX INV、共享数据和系统管理。
2. 模块级：任务台账、业务操作台、数据维护。
3. 台账级：待处理、待出具、历史记录、全部记录。
4. 记录级：右侧覆盖式详情抽屉，不改变台账宽度。

状态映射：

| 模块 | 待处理 | 待出具 | 历史记录 |
| --- | --- | --- | --- |
| WHT | `draft`, `pending_review` | `approved` | `issued`, `voided` |
| TAX INV | `draft`, `needs_review`, `ready` | `approved` | `issued`, `voided` |

历史文件导入是业务操作，不等于“历史记录”视图。前者是数据进入系统的方式，后者是
已出具或作废记录的生命周期归档。

## 公共组件

- `FinancePageHeader`：26px 无衬线页面标题、说明、模块页签和操作区。
- `FinanceLifecycleTabs`：固定阶段顺序与计数，WHT / TAX INV 只提供状态映射。
- `FinanceStatusBadge`：语义状态色；业务类别不得借用成功/警告/危险色。
- `FinanceRecordDrawer`：440px 覆盖式详情、统一标题/状态/页脚动作。
- `formatFinanceAmount` / `formatFinanceDateTime`：金额与日期显示的唯一入口。
- `tokens.css`：字体、颜色、间距、圆角、动效和兼容变量。

## 并行功能变更的界面落位

| 功能 | 页面位置 | 交互约束 |
| --- | --- | --- |
| WHT 批量开具 | 业务操作台 / 导入菜单 | 与历史迁移并列但明确标注“建草稿” |
| WHT 批量审批 | 待处理台账工具条 | 勾选后原位切换，显示各动作适用数量 |
| WHT 历史迁移 | 业务操作台 / 导入菜单 | 明确说明沿用旧编号并直接进入已出具 |
| 收入类型与默认税率 | 新建 WHT 表单 | 先选收款方，再按 PND3/PND53 过滤并显示税率 |
| 签名适用范围 | 数据维护 / 签名图库 | 显示 WHT、TAX INV、两者通用；默认值按范围独立 |
| TAX INV 出票签名 | 待出具详情动作 | 生成前确认是否盖章及签名版本，不静默跨范围选择 |
| BOT 配置自检与多币种 | 数据维护 / 汇率 | 紧凑提示配置状态；报价表优先展示 Buying Transfer |

这些功能来自并行工作树的在途实现。合并时以业务 API 和数据库迁移为准，但页面结构、
组件、密度和颜色必须继续遵守本文件；不得恢复分栏挤压台账、大号衬线标题或卡片拼贴。

## 桌面适配

- 1600×900：WHT 与 TAX INV 的主要核对列全部可见。
- 1366×768：不得产生页面级横向滚动；金额、日期和状态仍须首屏可见，长文本可省略。
- 抽屉打开前后台账宽度保持不变；关闭详情、无选中记录或空数据时不得预留右侧空列。
